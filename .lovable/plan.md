# Portfolio polish pass

## Goal
Keep the current Field Notebook identity, while making the portfolio feel more intentional, easier to scan, and more convincing for UI/UX hiring managers and clients.

## Improvements
- Refine the navigation with clearer active states and a more recognizable personal mark without increasing visual weight.
- Tighten the home introduction’s spacing and type balance, especially on mobile, so the first screen feels composed rather than long.
- Strengthen project cards with clearer hierarchy for project name, scope, role, and action while preserving the editorial asymmetric grid.
- Improve the About page’s experience and skills presentation so it reads as a professional capability profile rather than a plain list.
- Add restrained interaction polish to links and project imagery, with accessible keyboard focus and reduced-motion support.
- Correct small consistency issues in page numbering and shared contact labeling.

## Guardrails
- Preserve the off-white, charcoal, vermilion, serif/grotesk/mono visual system.
- Keep all content and project-scope claims honest; do not invent results, employers, dates, or contact details.
- Avoid extra cards, gradients, decorative effects, or heavy animation.
